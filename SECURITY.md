# Security

The programs built with this toolkit read files the player chooses (a ROM set, `settings.ini`,
save states, the settings memory) and nothing from the network. A file that makes a game or the
launcher read or write outside its own memory, or start another program, is a real bug and worth a
private report.

Please report such a thing privately through GitHub ("Report a vulnerability" on the repository's
Security tab) or to tmcleroy@gmail.com, and not in a public issue.

Only the latest version is supported.
